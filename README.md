# Temnorid Arena: Maps

`temnorid-arena-maps` is the Temnorid Arena arenas stored as Scene JSON, with spawns and objective sites.

It is a game package: it holds Temnorid Arena's own rules and content, built on the **IT-Kamianets 3D Engine** packages.

### Logic

An arena is a level, so it is data, not code: a `3d-scene-schema` document loaded through `3d-unity-scene`, with its models loaded by id through `3d-unity-assets`.

This package adds what the match needs from a map: team spawn points, objective sites, buy zones, and bounds, read by `temnorid-arena-core`. The server and clients load the same Scene JSON, so they always agree on the map.

### Status

Version 0.1.

* `ArenaMap`: loads an arena (Scene JSON TextAsset) with its prop libraries through `3d-unity-scene` and `3d-unity-assets`, asset catalogs mapping ids to models made in Unity (imported GLB files), separate floor and wall materials, and registers its `spawn` markers as `IArenaSpawns`.
* **First arena** (`Runtime/Arenas/first-arena.scene.json`, schema 1.1.0, generated by `Tools~/make-first-arena.cjs`): a 40 × 40 m stone floor, four 4 m walls, a central platform, 8 pillars, 2 broken pillars, 2 low walls and 6 crates for cover, corner braziers, a banner on each wall, rubble, and 8 spawn points with spawn circles facing the centre (`surface:*` tags for footsteps). `arena-props.library.json` has placeholders for every prop, used when no model is mapped.

Checked: both files validate against their schemas; in Play mode the arena loads 46 objects with 37 models from the game's catalog (no placeholders) and 8 spawn points.
